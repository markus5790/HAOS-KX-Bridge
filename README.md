# KX-Bridge Home Assistant App

Home Assistant OS packaging for [KX-Bridge](https://gitea.it-drui.de/viewit/KX-Bridge-Release), the Moonraker-compatible bridge for Anycubic Kobra X.

## Install

In Home Assistant: **Settings → Apps → App store → ⋮ → Add repository**

Repository:
`https://github.com/markus5790/HAOS-KX-Bridge`

Then install **KX-Bridge**, start it, and use **Web UI**.

Supported: `amd64`, `aarch64`.

For OrcaSlicer use Moonraker:
`http://HOME_ASSISTANT_IP:7125`

Additional printer ports: 7126-7130.

The upstream KX-Bridge project remains maintained by its original authors. This repository provides the Home Assistant packaging.
